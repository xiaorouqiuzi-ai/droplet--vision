# Portable Review Package — compatibility note

Portable Review Package has been generalized to **Annotation Package**.
See [Annotation Package](annotation_package.md) for current menus, uniform sampling,
annotation-from-zero and review workflows. Older `.dvrpkg` files remain supported;
new exports default to `.dvapkg`.
