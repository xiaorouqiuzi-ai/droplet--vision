# Configuration examples

Examples describe future adapter contracts, not runnable models. No loader is
implemented yet. Copy examples to ignored `*.local.yaml` files for local paths.
`model_id: null` means no registered model; `applicable_states: []` means scope
is unspecified and unvalidated, not validated for every state. Backend names
are proposals and do not imply installed dependencies. No thresholds or
weights are supplied. See docs/model_strategy.md for registry requirements.
