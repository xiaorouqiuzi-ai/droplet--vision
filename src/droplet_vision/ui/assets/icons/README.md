# Application icon

Source: repository `planico.jpg` (user-supplied artwork).
Source SHA-256: `6be0685b12f20c3748393a2db6edb6ae76e387cdc64105bf7ba7c48cc38cf677`.

`planico.png` is the transparent background-extraction result from the built-in
imagegen tool. The source JPG is unchanged. Edit instruction: remove only the
surrounding white textured paper; preserve the grey character, black outline,
pink features, interior white highlights/tooth, pose and texture, with a small
transparent margin. No replacement artwork or internet image was used.

`planico.ico` packages the transparent result with aspect ratio preserved on a
square canvas, at 16, 24, 32, 48, 64, 128 and 256 pixels, using Pillow. Both assets
are packaged with the optional Qt UI. The application loads these files locally;
there is no runtime image-generation dependency.
